# Astro Starter Pro - Editor Guide

Welcome to Astro Starter Pro! This guide will help you manage content on your site.

## Quick Links

- [Pages](cloudcannon:collections/pages) - Edit and create website pages
- [Blog](cloudcannon:collections/blog) - Manage blog posts
- [Site Settings](cloudcannon:collections/data) - Update site-wide settings

## Managing Pages

### Editing Existing Pages

1. Click on **Pages** in the sidebar
2. Select the page you want to edit
3. Use the visual editor to make changes directly on the page
4. Click **Save** when done

### Creating New Pages

1. Go to **Pages** in the sidebar
2. Click the **+ Add** button
3. Choose either:
   - **Page** - A simple page with a title and content
   - **Page Builder** - A page built from reusable content blocks

### Page Builder Blocks

When editing a Page Builder page, you can add these content blocks:

- **Hero** - A large banner section with title, tagline, and buttons
- **Features** - A grid of feature cards with icons
- **Content Section** - A two-column layout with text and an image
- **Values Grid** - A configurable grid of value cards
- **Service List** - A list of services with icons

To add a block, click the **+** button in the page builder area.

## Managing Blog Posts

1. Click on **Blog** in the sidebar
2. Click **+ Add** to create a new post, or select an existing post to edit
3. Fill in the post details:
   - **Title** - The post title
   - **Description** - A brief summary
   - **Date** - Publication date
   - **Author** - Who wrote the post
   - **Image** - Featured image (optional)
   - **Tags** - Keywords for the post (optional)
   - **Category** - Post category (optional)
4. Write your content in the editor below
5. Click **Save** when done

## Site Settings

The **Data** section contains site-wide settings:

- **site.json** - Site name, description, navigation links, and social media URLs

## Tips

- Changes are saved to your repository when you click Save
- Use the **Preview** button to see how your changes will look
- The visual editor lets you edit text directly on the page
- Use the data panel (sidebar) for structured fields like dates and categories
